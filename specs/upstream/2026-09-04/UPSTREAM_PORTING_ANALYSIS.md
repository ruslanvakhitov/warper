## Skip groups

The remaining 887 skipped commits fall into these evidence-backed groups:

- Hosted Warp, Oz, cloud tasks, accounts, billing, Drive, shared sessions, telemetry, and upstream release-service work conflict with WARPER-001.
- TUI and WASM work belongs to product surfaces that Warper does not launch or specify.
- Windows-specific changes are outside the current platform scope under WARPER-007.
- New agent orchestration, plugin and control APIs, OAuth, watchers, background automation, and third-party harness infrastructure are outside WARPER-005.
- UI polish, onboarding, settings discovery, completion metadata, and minor compatibility changes do not clear the XP necessity bar.
- Refactors, renames, test-process changes, dependency churn, and internal team tooling have no proven retained Warper failure.
- Changes whose code paths or dependencies are absent, unreachable, or already covered locally require no port.
- Container and enterprise NSS handling, the removed remote daemon, and the disabled legacy SSH wrapper are outside the supported local terminal workflow.
